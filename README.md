# FSD Lab Assignment 2: Reading Room Library

Name: Pratham Singh  
PRN: 1032211384

A college library site covering form validation, DOM and jQuery.

- `index.html`, `validation.js`: student registration form with validation, a cookie and session storage
- `catalogue.html`, `catalogue.js`: DOM operations and jQuery
- `library.css`: shared external styles

Open `index.html` in a browser. An internet connection is needed for jQuery and the fonts.
